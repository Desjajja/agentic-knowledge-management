## pi 的参与

此前 `tools: []` 禁用了所有工具。现在回答会注册并启用两个实际运行在 pi SDK 工具循环中的工具：

- `akm_search`：按当前项目搜索，返回短片段和可读引用。
- `akm_read`：只读已发现页面，核对哈希，最多每次 8000 字符，返回下一偏移和是否截断。

初始问答正文预算从每页 16000 / 总计 64000 字符，缩减到每页 4000 / 总计 16000 字符。长页按需读取。工具结果、读取的分段和回答可追溯；没有开放绕过提案审核的正式知识写入。提取阶段仍读取完整既有页面以保护更新事实，不宣称所有阶段都已改成按需加载。

真实模型验证：要求搜索 Snapshot Isolation 并按 2000 字符分页读完。模型实际调用了 1 次搜索、4 次读取，随后根据原文作中文回答，正确区分 classic/strong SI 和 generalized/weak SI 与 serializability 的关系。完整记录在 `artifacts/ux-validation-2026-10-12/real-tool-loop.json`。
