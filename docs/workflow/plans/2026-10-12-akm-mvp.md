# AKM MVP Implementation Plan

**Goal:** 本轮交付实际可用的新增、修改、检索闭环，以及固定检索数据集、质量基线与回归检查。

**Architecture:** Node.js ESM CLI，pi SDK 作为隔离的模型编排运行时；文件系统 Vault 为权威存储，YAML Properties 与项目索引面向 Obsidian；检索与事务由确定性核心执行。

## Global Constraints

- 默认根目录 `~/.akm`，测试/demo 使用临时根目录，不修改用户全局 pi 配置或真实知识库。
- 不引入 scope；每页一个主项目，显示稳定 label、内容和最小归档信息。
- 所有正式知识写入先形成提案，再以检查过的 revision 和选中 items 提交。
- 来源、副本、ledger 均在 Vault 内，保存相对定位；目标被外部修改时拒绝覆盖。
- 查询显式启动；query 不保存回答，不依赖模型或网络才能返回片段。
- benchmark 固定数据与 relevance judgments；质量指标与延迟分开报告，基线哈希不一致时拒绝比较。
- pi 真实 SDK 集成必须有无凭据的本地兼容 endpoint 集成测试；不能用模拟 pi 代替 SDK。

## 多阶段交付

1. **本轮 MVP**：默认库、项目归属、提案增/改、事务恢复、文本摄取与对话提取、显式检索、pi provider 隔离、CLI/skill、benchmark。
2. **异步与交互增强**：独立 worker、任务取消/恢复、提案自然语言编辑与合并、更多输入解析器。
3. **模块化**：模块 export/import、依赖策略、链接重写与迁移验证。
4. **检索优化**：真实脱敏语料集、分块/向量/重排实验、扩展 benchmark 和版本兼容。

### Task 1: 基础与路径透明

**Files:** `package.json`, `bin/akm.js`, `src/storage.js`, `tests/cli.test.js`
**Consumes:** `docs/akm-design.md`
**Produces:** 默认根目录配置、self-describing Vault 与工作区解析，结构化 CLI 输出。
**Steps:** 固定实际 SDK 版本；名称/ID 定位；按相对路径绑定；检查路径、重名和无默认库；说明 Node 最低版本。
**Acceptance:** 临时根初始化后可从不同 cwd 查询同一个 Vault；复制根目录仍可定位。

### Task 2: 提案与事务增改闭环

**Files:** `src/knowledge.js`, `src/transaction.js`, `tests/knowledge.test.js`
**Consumes:** Task 1 的 Vault 解析。
**Produces:** 稳定编号、revision、预览、选中提交；原文、正式 Markdown、项目索引与 ledger。
**Steps:** create/update 目标快照；Properties 与已有自定义字段保留；排除项不写入；新项目在同一事务创建；锁与恢复日志，失败回滚，幂等重试；来源只保存明确输入片段。
**Acceptance:** 新增→修改→读取实际正文；外部编辑冲突、旧 revision、路径逃逸、未选项、失败恢复均有行为验证。

### Task 3: 检索与 benchmark

**Files:** `src/retrieve.js`, `src/benchmark.js`, `benchmarks/retrieve-v1.json`, `tests/retrieve.test.js`, `tests/benchmark.test.js`
**Consumes:** 实际 Markdown 页面和 properties。
**Produces:** BM25 + metadata 字段权重检索、可引用行号片段；固定相关性集、版本化 baseline、对比结果。
**Steps:** 中文分词使用字符与双字片段，英文规范化；title/alias/tag/content 检索；project filter；实时读取避免陈旧索引；对照基础 BM25；报告 Recall@k、MRR@k、nDCG@k、无结果正确率、分组及每 query 结果，p50/p95；比较数据指纹与质量阈值。
**Acceptance:** 质量回归返回非零退出码；负样本、多个相关页、跨项目/过滤、别名与中文测试；基准无需网络且重复质量一致。

### Task 4: pi 与两个输入入口

**Files:** `src/pi.js`, `tests/pi.test.js`, `skills/akm/SKILL.md`
**Consumes:** 提案 JSON 与检索 API；pi 官方 SDK 文档和已安装声明。
**Produces:** workspace-local provider 设置、实际 SDK 文本/对话提取为 proposal；显式 answer 可引用证据。
**Steps:** 隔离模型/auth/settings/resources，无 shell/write tools，无全局发现；env 凭据；严格校验模型输出；网络超时与错误；本地 OpenAI-compatible 测试 server 捕获请求验证模型与上下文。
**Acceptance:** SDK 能实际调用本地 endpoint 生成提案/回答，两个 workspace 配置隔离；错误输出不触发知识写入。

### Task 5: 交付与审查

**Files:** `README.md`, `scripts/demo.js`, `docs/mvp-validation.md`, 本计划。
**Consumes:** 全部实现和测试结果。
**Produces:** 可运行说明、无密钥 demo、基准结果、独立审查及修复。
**Steps:** 跑完整测试与 benchmark；真实 CLI 演示新增/改/查；只读 reviewer 审查重要问题并修复；记录未实现的后续阶段。
**Acceptance:** 用户能按 README 使用 CLI，benchmark 可用于未来回归，主要问题已修复，goal 仅在全部交付后完成。
